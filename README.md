# Calculator

## Overview
This project is a simple calculator developed using HTML, CSS, and JavaScript. It provides a clean user interface for performing basic arithmetic calculations.

## Features
- Addition, subtraction, multiplication, and division
- Support for decimal numbers and parentheses
- Clear (AC) button to reset the display
- Keyboard input support
- Error handling for invalid expressions and division by zero
- Responsive and user-friendly interface

## Technologies Used
- HTML5 — Structure of the calculator
- CSS3 — Styling and layout
- JavaScript — Calculation logic and user interactions

## Project Structure
```text
CodeAlpha_Calculator/
└── index.html
```

## How to Run
1. Clone or download this repository.
2. Open the `index.html` file in a web browser.
3. Enter an expression using the calculator buttons or keyboard.
4. Press `=` to calculate the result.
5. Press `AC` to clear the display.

## Purpose
This project was developed to practise frontend development fundamentals, including HTML structure, CSS styling, and JavaScript functionality.
